# 타브만든댕

음원을 브라우저에서 분석해 일렉기타용 단선율 타브를 만드는 로컬 웹앱입니다.

## 실행

1. `실행.bat`을 더블클릭합니다. Python 3.10 이상이 필요합니다.
2. 브라우저에서 `http://127.0.0.1:8765`가 열립니다.
3. 음원을 선택하거나 샘플 멜로디를 불러옵니다.
4. 튜닝, 최대 프렛, 시작 시간, 분석 길이를 선택하고 **타브 만들기**를 누릅니다.
5. 원곡과 비교해 확인한 뒤 TXT 또는 JSON으로 저장합니다. **인쇄 / PDF**로 PDF 저장도 가능합니다.

터미널에서는 `python server.py`로 실행할 수 있습니다. 서버 창에서 Ctrl+C로 종료합니다. HTML 파일을 직접 더블클릭하면 Web Worker가 제한될 수 있으므로 서버로 실행해주세요. 최신 Chrome 또는 Edge를 권장합니다.

## 현재 기능

- 최대 100MB 음원 업로드 및 드래그 앤 드롭
- 브라우저가 디코딩할 수 있는 MP3, WAV, M4A 등의 음원 지원
- 원곡 재생, 파형 표시, 15~90초 구간 분석, 분석 취소
- 8kHz 모노로 변환 후 YIN 방식의 단일 음 높이 추정
- 노트별 시작 시간, 길이, 음 이름 표시
- Standard / Drop D / 반음 다운 튜닝, 12·17·24 프렛 제한
- 줄 이동과 프렛 이동을 고려한 운지 선택
- 텍스트 타브, 노트 JSON, 인쇄용 레이아웃
- API 키, npm, 외부 패키지 없이 실행

음원은 외부로 업로드하지 않으며 새로고침하면 작업 내용이 초기화됩니다. 서버는 내 컴퓨터의 127.0.0.1에만 바인딩합니다.

## 정확도와 범위

첫 버전은 **한 번에 한 음을 연주하는 멜로디**를 분석합니다. 기타 독주나 미리 분리한 기타 트랙에 적합합니다. 보컬·베이스·드럼이 섞인 완성곡에서는 기타가 아닌 음을 잡거나 옥타브를 잘못 추정할 수 있습니다. 코드, 겹치는 음, 벤딩, 비브라토, 슬라이드, 해머링, 풀링은 구분하지 않습니다. 같은 음을 연속해서 치면 하나로 합쳐질 수 있습니다.

타브의 각 칸은 노트 순서입니다. **칸 간격이 박자를 나타내지는 않습니다.** 상단 숫자는 원곡 기준 초입니다. JSON의 start와 duration으로 시간 정보를 확인할 수 있습니다. `?`는 선택한 튜닝과 프렛 범위를 벗어난 노트입니다. 이는 자동 추정 결과이며 원곡의 공식 악보가 아닙니다.

완성곡에서 기타 파트를 추출하려면 다음 단계로 음원 분리와 다성 전사 모델을 붙여야 합니다. 현재 앱에는 이 모델들이 포함되어 있지 않습니다.

## 파일

- `index.html`, `style.css`: 한국어 화면과 반응형 레이아웃
- `app.js`: 업로드, 디코딩, 재생, 분석 제어, 타브 표시·내보내기
- `pitch-worker.js`: 음 높이 추정과 기타 운지 계산
- `server.py`, `실행.bat`: 로컬 서버와 Windows 실행 파일

## 검증

Chrome 헤드리스 브라우저에서 MIDI 40·45·52·64·69·76·88의 음 높이 검출, 무음 처리, 저음 E 및 24프렛 고음 E 운지, 음역 밖 처리를 확인했습니다. 샘플 음원의 실제 Web Worker 분석에서 12개 음의 순서가 예상과 일치했고 타브와 노트 테이블 생성까지 확인했습니다. 다양한 실제 곡의 정확도와 모든 파일 형식의 호환성은 추가 검증이 필요합니다.
